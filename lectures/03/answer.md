# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の素のLLMは、モデル自身の知識をもとに直接回答するのに対し、第3回のエージェントは、質問内容に応じてツールを呼び出し、その結果を参照して回答する点が異なる。例えば「LoRAとは何ですか？」という質問では、search_glossary を使用して用語集の情報を確認してから回答した。また、「第3回では何を学びますか？」という質問では、get_lecture_summary を使用して講義資料の内容を取得してから回答した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：「LoRAとは何ですか？」では、search_glossary({'query': 'LoRA'}) が呼び出された。
「第3回では何を学びますか？」では、get_lecture_summary({'lecture': 3}) が呼び出された。
- 1つの質問での LLM 呼び出し回数（`requests`）：どちらの質問でも requests=2 だった。1回目で質問内容を判断して必要なツールを呼び出し、2回目でツールの実行結果をもとに最終的な回答を生成していると考えられる。
- 追加したツールと、docstring に書いた説明：今回確認したエージェントでは、新しいツールの追加は行わず、既存の search_glossary と get_lecture_summary を使用した。search_glossary には「講座の用語集から用語を検索し、定義と、どの回で扱うかを返す」と説明されている。get_lecture_summary には「指定した回（1始まりの整数）の講義の要点を返す」と説明されている。

## 宿題

- 取り組んだレベル：基礎
- やったこと：app/agent.py の INSTRUCTIONS を書き換え、質問の種類に応じて使用するツールをより明確に指示した。具体的には、AIや講座に関する専門用語については search_glossary を必ず使用し、講義内容については get_lecture_summary を必ず使用するようにした。また、ツールで確認できない情報については推測せず、用語集に情報がない場合は明確に伝えるよう指示した。変更後、「LoRAとは何ですか？」と「第3回では何を学びますか？」を --trace 付きで実行し、変更前後のツールの呼び出し方や回答を確認した。
- 結果：「LoRAとは何ですか？」という質問では、変更後も search_glossary({'query': 'LoRA'}) が呼び出され、用語集の情報をもとに回答された。また、回答の最後は指示どおり「関連：第2回」という形式になった。
「第3回では何を学びますか？」という質問では、get_lecture_summary({'lecture': 3}) が呼び出され、第3回の講義内容をもとに回答された。こちらも最後に「関連：第3回」と表示された。
- 気づき・疑問：INSTRUCTIONS の書き方を具体的にすることで、エージェントがどのような質問に対してどのツールを使用するかを明確に制御できることが分かった。一方で、今回の「LoRAとは何ですか？」では、変更前から search_glossary が正しく呼び出されていたため、指示を変更してもツールの呼び出し結果自体は大きく変化しなかった。今後は、複数のツールのどちらを使うべきか判断が難しい質問や、用語集に存在しない質問でも試して、指示文の違いがエージェントの行動にどの程度影響するか確認したい。
